# Cyber Tic-Tac-Toe

A cybersecurity-themed Tic-Tac-Toe game made with Python and tkinter only.
Mini project for ITE 260 Computer Programming 1, College of Information Technology Education, PHINMA - University of Iloilo.

## Features

- 1 player (vs AI) or 2 players
- Play as X or O
- 3 difficulty levels: Script Kiddie (easy), Pentester (medium), Elite Hacker (hard)
- Plot twist: a virus breach randomly flips one mark during the game
- Sound effects and background music (Windows only)
- Score board for X, O, and draws

## Controls

| Key | Action   |
|-----|----------|
| S   | Start    |
| P   | Pause    |
| X   | Settings |
| C   | Continue |

## How to Run

1. Install [Python 3](https://www.python.org/downloads/). tkinter is already included.
2. Download `cyber_tictactoe.py` from this repository.
3. Open a terminal in the folder of the file and run:

```
python cyber_tictactoe.py
```

## Notes

- Sound and music use `winsound`, which works on Windows only. On Mac and Linux the game uses the system bell and has no music.
- Scores are not saved after the game is closed.
